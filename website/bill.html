How comments work / for editors

Comments are public and stored as GitHub issues. You can post directly from this page, no account needed. If the campaign server is unavailable, GitHub opens with your comment pre-filled instead, and you click Create there (free GitHub account).

Editors: open a comment's “View on GitHub” link. Add the accepted label to approve it: an automated workflow merges the proposed text into the bill, records the previous version, and the commenter receives a gold star. Add the hidden label to remove spam or abuse from this page.
