# San Francisco CAREN Act Documents

The original ordinance PDF (Ordinance No. 219-20, File No. 200735, Police Code §637) has been downloaded and should be placed here as `SF-CAREN-Act.pdf`.

Source: San Francisco Board of Supervisors (https://sfbos.org/sites/default/files/o0219-20.pdf or archive).

Key provisions:
- Unlawful to knowingly cause a peace officer to contact a person with specific intent to discriminate on listed protected characteristics or to cause listed harms (constitutional infringement, harassment, expulsion from lawful place, reputation/financial damage).
- Private civil cause of action with damages of at least $1,000 + attorneys’ fees + costs, and possible punitive damages.
- Explicitly not intended to discourage good-faith emergency calls about real danger or actual crime.
